# Orbit API and table guides

This folder explains how the frontend talks to Orbit's API and how the API's
main tables fit together. Start with [Users, profiles, and settings](users.md)
for registration, login, profile editing, the settings screen, and user lookup.

## Guides

| Guide | Covers |
| --- | --- |
| [Users, profiles, and settings](users.md) | `users`, `user_profiles`, `user_preferences` and their API endpoints |

The guides describe the current backend behavior. If a guide and the route
implementation disagree, the route implementation is the source of truth and
the guide should be updated.
